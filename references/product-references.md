# Product References

> **Purpose:** a high-signal reference stack for building excellent digital products.
>
> **Filter:** free to browse/use as a reference, primary sources where possible, research-backed when the question is behavioral, and aggressively curated when the question is visual.
>
> **Rule:** this is **not** a directory of directories. `★` means “open this first.”
>
> Last reviewed: **2026-09-07**

---

## 0. The product-side hierarchy

When making a product decision, use references in this order:

1. **Observed user behavior / research**
2. **Platform and accessibility standards**
3. **Production design-system patterns**
4. **Exceptional real-world references**
5. **Aesthetic inspiration**
6. **Trends**

Never reverse that order just because a screenshot looks good.

| Reference | Use it for |

Design AI experiences around **capability boundaries, uncertainty, recovery, permissions, latency and user control**.

## 22. Product critique checklist

Before calling a product surface “done,” check it against:

### Problem
- Is the user problem explicit?
- Is the primary job obvious?
- Is the product solving a real constraint rather than adding UI?

### Information
- Can a new user orient themselves immediately?
- Is hierarchy clear without decoration?
- Are labels concrete and predictable?

### Interaction
- Are states complete: default, hover, focus, pressed, loading, empty, error, success, disabled?
- Does every action have feedback?
- Can destructive actions be recovered from where appropriate?
- Does keyboard behavior make sense?

### Visual
- Is typography doing most of the hierarchy work?
- Is spacing systematic?
- Is color carrying meaning intentionally?
- Is motion communicating state/causality rather than showing off?

### Accessibility
- Keyboard
- Focus
- Contrast
- Zoom/reflow
- Screen-reader semantics
- Reduced motion
- Touch targets
- Error identification

### Product
- Does the surface advance the core user value?
- Is the success metric defined?
- Is there evidence behind the decision?
- What would make you reverse the decision?
