GENERAL GUIDE — DESIGN KIT
Updated: October 8, 2026.

PURPOSE
Design Kit helps decide visual UI direction with GENERATED IMAGES, one section at
a time. It does NOT automatically create the real final design, components,
Figma pages or frontend code. The user decides any subsequent implementation.

FLOW
1. Start from the USER's actual design foundation. Agent suggestions are
   proposed until the user accepts or delegates them.
2. Choose the first high-leverage section and write a highly specific prompt.
   Generate section IMAGES, comparing meaningfully different arrangements.
3. Iterate repeatedly in material chunks: composition, hierarchy, type/image
   relationship, asset framing and visual density. Preserve the strongest image.
   There is NO automatic two-refinement-pass limit.
4. Use the selected first image plus foundation as visual references for each
   subsequent section. Resolve each one through image rounds.
5. Arrange selected section images in page order. Inspect overall rhythm and
   consistency; revise the offending sections until the page is visually decided.
6. STOP. The user separately chooses whether/how to build the actual design.

Existing Awwwards / One Page Love MCP research remains useful for concrete visual
questions. Reuse user-supplied images first and do not force discovery on every
round. Existing provider integrations and reference catalog are preserved.
Third-party prompting/design skills are optional experiments, not assumed gains.

STARTING REQUEST
"Use Design Kit with image generations only. Take my current foundation,
iterate the first section with significant composition changes and detailed
prompts, and use the chosen image to anchor all following sections. Once the
ordered page is visually decided, give me the selected images and stop before
creating the actual design."

Keep selected image versions, exact prompts, foundation status and user approvals
in the target project's existing record. Mark unavailable image tools or unknown
costs honestly. Package tests do not demonstrate improved images or tool access.
Canonical instructions: SKILL.md and IMAGE_WORKFLOW.md.
