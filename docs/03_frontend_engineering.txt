IMPLEMENTATION IS A SEPARATE USER-SELECTED TASK
Updated: October 8, 2026.

Design Kit no longer owns frontend creation or QA as an automatic phase.
Its job is user-foundation-led, image-based section exploration and a selected
whole-page visual direction. Do not treat completion of the image storyboard
as authorization to create Figma designs, components, HTML/CSS, React or a
published application.

When asked for a handoff, provide actual selected image paths/versions, section
order, user-approved and proposed foundation decisions, exact content/assets
when known, dominant composition/imagery relationships, responsive unknowns,
provenance and unresolved constraints. Be explicit that these are still images,
not tested UI behavior or coded responsive states.

Legacy SOFTWARE.md, PRODUCT_DELIVERY.md and QA.md are retained for possible
separately authorized frontend work outside the Design Kit workflow. They must
not override SKILL.md's stop boundary or auto-start implementation.

The user controls whether, when and where a separate implementation proceeds.
