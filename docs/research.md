UI Craft and Anti-slop names are ambiguous. The exact repositories reviewed above
make the interpretation reproducible; another similarly named project has not
silently been treated as the same source. Source commits are research snapshots,
not a promise that these remain latest when the plugin is used.

Reviewed primary SKILL.md files, Impeccable/router context, Checklist audit and
critique references, Product Design index/research/audit/ideate/design-qa instructions,
and upstream metadata/licenses where stated. No upstream material is vendored.
The classification used by the installed plugin is: UI Craft, Anti-slop, OpenAI
Product Design and Anthropic frontend-design contribute **CORE INTERNAL KNOWLEDGE**
through original synthesis; Checklist Design and Interface Design are **OPTIONAL
EXTERNAL SPECIALISTS** when actually installed and compatible; Impeccable is
**DEVELOPMENT/BENCHMARK ONLY**; incompatible modes are **EXCLUDED**. No specialist
supplies a necessary tool unavailable through native Codex plus a verified Figma
transport.

Impeccable was installed on 2026-09-04 as the user-level skill at
`C:\Users\ib\.codex\skills\impeccable` using the official skill installer and exact
revision above. The project-local context command was deliberately not run: its own
4.2.0 setup can create PRODUCT.md, DESIGN.md, `.impeccable`, surface briefs, hooks,
or download a binary, which would violate this plugin's normal-use artifact rules.
Installation proves discoverability for a later task after runtime refresh, not
compatibility, invocation, or design-quality benefit.

The official Figma source snapshot in the registry reported 2.0.20; the installed
official plugin tested here is 2.0.21. Its actual `figma-use`, screen generation,
library generation and new-file skills were inspected and remain available as an
optional fallback. The primary development transport is the separately installed
`southleft/figma-console-mcp` v1.40.0 tag at commit
`e4d5605e6108cd0b21a950f6f57fc189749bd2eb`. Practical due diligence confirmed active
maintenance/community use, MIT licensing, documentation, the claimed local Plugin API
bridge, loopback binding, and the v1.38.2 process-health safeguards. The user-level
Codex configuration allowlists design reads/writes and blocks filesystem extraction,
cross-file, cloud, comment, history, FigJam, Slides, and code-scan tools. A live local
smoke test established editable creation and current-state screenshots without a PAT.

Craft guidance was rechecked 2026-09-04 against current Carbon typography, spacing,
and grid pages, Apple layout, Material adaptive layout, Fluent motion, and WCAG 2.2.
Design Kit retains relational principles about hierarchy, rhythm, adaptation,
choreography, and accessibility. Vendor tokens, breakpoints, timings, and visual
style are scoped examples rather than cross-product doctrine; source entries and
verification dates are in the skill's `references/sources.json`.
