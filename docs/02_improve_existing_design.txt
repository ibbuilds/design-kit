IMPROVE AN EXISTING VISUAL DIRECTION — IMAGE FIRST
Updated: October 8, 2026.

Preserve accepted foundation decisions, earlier image versions, protected
assets/content and selected sections. Existing code can identify real content
or constraints, but Design Kit does NOT edit that code.

Locate the weak section image and the specific visual mismatch. Inspect its
composition in context with the selected first section and neighboring images.
Specify what to preserve, what significant structural/type/image treatment to
replace, and how the expected visible result differs. Generate image revisions
and keep the strongest comparison candidate. Do not substitute micro-polish
for a weak visual premise.

For several affected sections, return to the same foundation and image anchor;
do not redesign a whole page in one unconstrained generation. Review the
ordered set and fix drift by revising individual section images. Distinguish
agent-selected images from the user's approval. Separate desktop/mobile imagery.

Use existing Awwwards/One Page Love MCP research for material visual gaps when
needed, not as mandatory browsing. Third-party skills are optional and should
be evaluated on actual images.

Deliver selected images, prompts, foundation updates and remaining visual
unknowns. STOP before the actual editable design or implementation. The user
decides that separately. No fabricated render inspection or claimed UI behavior.
