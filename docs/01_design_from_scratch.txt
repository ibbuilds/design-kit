DESIGN FROM SCRATCH — IMAGE-FIRST AND COMPONENT-FIRST
Updated: October 8, 2026.

Any single text/visual element, component, family, section or page is a valid
requested unit. Do not expand a small request into a compulsory whole design.

For a multi-part product, start with a user foundation or KIT-PROPOSED visual
direction, clearly distinguishing proposal from acceptance. Use relevant
actually inspected Awwwards / One Page Love reference images to inform open
aesthetic choices. Don't demand a completed token system.

Generate images of a first high-leverage COMPONENT or typographic treatment.
Explore meaningful differences in proportion, typography, geometry, material,
color roles or framing until the user recognizes the intended style. Keep
the strongest image. AFTER EVERY ROUND ask what to refine, select, change,
reuse or stop. No fixed two-refinement-pass ceiling.

Reuse the selected first-component image across siblings. As shared styling
stabilizes, generate related component IMAGES IN GROUPS and compare their
visual consistency. The user or Design Kit may keep refining the image-based
library until the user's chosen quality milestone.

If requested, use accepted components as the visual anchors for the first
section and subsequent section images, then optionally a whole page. A direct
full-page image iteration is also valid when requested. The user can stop
at any milestone. No coded/editable final design or conversion is implied.
