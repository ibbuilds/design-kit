DESIGN DIRECTION FROM SCRATCH — IMAGE FIRST
Updated: October 8, 2026.

Begin with the user's own partial or complete visual foundation, not with a
coded page. Foundation choices include intended impression, type/color roles,
geometry, density and imagery. Clearly label proposed vs accepted values.
You do not need a final token inventory or component library.

Choose a representative first section, specify its real content, visual job,
image dimensions and foundation, then generate multiple IMAGE compositions.
Look for substantial differences in region balance, headline hierarchy,
asset scale/crop and art direction; compare at normal viewing size.
Repeat meaningful rounds until the section's visual direction is selected.
Do not impose a universal two-pass budget; obey user budget/tool limits.

Use that selected image as a reference for the next section, along with the
same foundation. Repeat section by section. Existing Awwwards / One Page Love
MCPs are optional targeted inspiration; preserve rather than reinstall them.

When all requested sections have selected images, arrange them in page order,
check overall rhythm and revise weak transitions by changing the section images.
Deliver the visual decision and selected imagery. STOP before final design,
components or code. Only the user may choose that separate next workflow.
