# Observe, diagnose, correct

Judge the requested scope against the brief, human decisions, necessary content/UX,
selected reference mechanisms and relevant craft. The primary session judges.
Geometry complements a current render; it cannot prove visual quality. Follow
[Figma's fresh-evidence rule](figma.md) after every meaningful change batch.

Inspect overall hierarchy/rhythm, important sections at reading scale, and implicated
micro-details close up. Check composition, type relationships, real content, crops, contrast, navigation,
state meaning and construction where relevant. Catch overlap, clipping, broken mobile,
placeholder residue and generic first-pass composition. A thumbnail cannot certify
body text; a hero cannot establish a whole experience. Static Figma cannot certify
runtime keyboard behavior, screen readers or unseen motion.

For substantial net-new work, inspect [system integrity](design-foundations.md#refine-the-system-and-artifact)
alongside pixels: definitions must actually drive the composed instances and responsive
surfaces. Resolve a shared weakness in the system and recheck its affected uses.

Reason: observed location/state → concrete cause → bounded intervention → expected
benefit → fresh visual comparison. Preserve strengths and human edits. Compare
equivalent regions/density with references; transfer mechanisms, not identities.
Fix structure before decorating, and relationships before 1px nudges.
For high ambition or credible under-finish, use [finish intelligence](craft/finish.md);
clean geometry alone does not establish exceptional expression. Reject a generated
asset whose visible meaning or placed crop contradicts its intended section, even
when technically valid and visually attractive.

For expressive whole-page work, distinguish useful content containers from uniform
box isolation and equal-weight sections; use [spatial composition](craft/composition.md)
only when this weakens the story. Also separate accurate product UI from effective
marketing presentation: a correct flat UI can still need stronger framing or context.

| Finding | Action |
|---|---|
| Objective/material defect | Fix within authorized scope and recheck the region. |
| Consequential visible gap + credible improvement hypothesis | Try the targeted change even if no technical defect exists; keep only an observed improvement. |
| Subjective alternate taste | Stop or let the user choose; do not churn a strong direction. |
| Intentional human decision | Preserve unless asked to reconsider it. |

For substantial high ambition, distinguish “no defects” from “no high-leverage credible
improvement.” A visibly under-resolved relationship with a supported intervention remains
unfinished; a merely imaginable effect does not. Judge resolution of the chosen language,
including transferred reference relationships, not how many craft devices were used.
Stop when no material defect or consequential credible improvement remains, an unresolved user preference
determines the remaining alternatives, or the user stops. Ordinary aesthetic decisions
belong to the primary model. Repeated failed changes require a new diagnosis, better evidence
or a simpler direction, not blind retries or an arbitrary attempt-count cutoff. If no
credible next intervention remains, state the unresolved weakness and stop. Report blocked visual claims when
fresh rendering is unavailable. Technical validity, policy compliance, specialist
agreement or arbitrary scores do not establish quality.
