# Optional in-session craft guidance

Design Kit works without external specialists. Use additional guidance only for a
distinct unresolved question that materially benefits the task. Read current available
instructions; an adapter, citation or installation is not actual use. Never silently
install a specialist or invoke an external service.

Impeccable may contribute bounded typography, composition, hierarchy, polish or critique
inside the primary session when compatible with the request. Exclude frontend/code
workflows, project scaffolding, hooks, repository memory, automatic audits and global
taste bans. If the available mode requires those effects, use Design Kit's internal
craft modules. Apply the same boundary to any other useful specialist; no default roster.

No handoff or nested session. The primary model interprets guidance, makes decisions,
performs all Figma actions and visually verifies the result. When asked for traceability,
distinguish available, actually used, not used and unavailable. Do not narrate an inventory
during ordinary design or imply that a missing specialist blocks core capability.
